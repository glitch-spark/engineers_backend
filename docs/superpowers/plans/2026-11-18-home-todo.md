# Home To-Do List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Home's Today card into a tickable to-do list (daily routines + all weekly goals, checkbox + number for number items), drop the update/edit links, and shrink This week / Metrics to strips.

**Architecture:** Backend: the shared done rule (`plan_save.result_done`) treats a tick as done for number items and keeps the stored done when a request doesn't send one; `plan_auto.goal_progress` gains `doneOn` and a target-reached done. App: shared `ItemRow` gets checkbox + number; `TodayCard` is rebuilt as two sections; `WeekCard` / `MetricsCard` become strips.

**Tech Stack:** FastAPI + Beanie (mongomock tests); React + SWR + Tailwind (vitest + Testing Library).

**Spec:** `engineers_backend/docs/superpowers/specs/2026-11-18-home-todo-design.md`

**Repos / branches:** backend `/home/eningeer/work/Engineer/engineers_backend` on `feat/home-todo` (spec commit 4671b44); app `/home/eningeer/work/Engineer/engineers_app` on `feat/home-todo` (from main 0ae2362). Main checkouts, no worktrees.

## Global Constraints

- Draft save (`PUT /daily-plans/{day}?submit=false`) never posts to Slack for an unsubmitted day; never touches `done` counts, `notes`, `targetOverride`.
- Count / hours done = sent done OR value ≥ target (value > 0 without a target); when `done` was not sent for an item, start from the stored done.
- API changes additive only (`progress[id].doneOn`).
- Mon–Fri working days; "days left" = Mon–Fri days after today.
- `.input` is unlayered CSS: width/padding utilities on inputs need `!` (e.g. `!w-16`).
- Commit messages single line, no co-author / "Generated with" trailers. Never commit the app's `.env.*`.
- Backend tests: `.venv/bin/python -m pytest -q -p no:cacheprovider tests_unit/<file>`; full run with `--ignore=tests_unit/test_resume_experience_roles.py --ignore=tests_unit/test_style_serializer.py --ignore=tests_unit/test_template_annotate_removals.py` (2 known local failures: `test_upload_url_without_storage_is_503`, `test_resume_prompts…[prompts5-new-1]`). Never run anything against the real DB (backend `.env` is production).
- App: `npx tsc --noEmit`, `npx vitest run <path>`.

## Review Focus

1. Slack form submit after a Home tick on a count item keeps it ticked (Task 1 `test_values_only_keeps_stored_done`).
2. Un-ticking a weekly goal done on an earlier day saves to that day, not today (Task 3 `unticks a goal done on an earlier day on that day`).
3. Typing the target amount ticks the row; ticking never clears the typed number (Task 2 tests).
4. A weekly count goal whose daily amounts sum to the target reads done for the week (Task 1 `test_goal_done_when_week_total_reaches_target`).
5. Weekend: no "days left", daily section shows only routines with results (Task 3 test).

### Task 1: Done rule + weekly goal `doneOn` (backend)

**Files:** Modify `app/plan_save.py` (`result_done` + its 2 callers), `app/plan_auto.py` (`goal_progress`). Tests: `tests_unit/test_daily_plan_progress.py`, `tests_unit/test_daily_plan_api.py` (or a new `tests_unit/test_done_rule.py`).

**Interfaces:**
- `def result_done(kind: str, value: Optional[float], sent_done: Optional[bool], target: Optional[float], old: Optional[ItemResult]) -> bool` — `sent_done is None` means "not sent". Rule: check → `bool(sent_done)` (None → `old.done` if old else False); count/hours → `base or value_rule`, where `base = sent_done if sent_done is not None else bool(old and old.done)` and `value_rule = value is not None and (value >= target if target else value > 0)`.
- Callers pass `r.done if "done" in r.model_fields_set else None`.
- `goal_progress(weekly, days) -> {id: {"value", "done", "target", "doneOn"}}`: `doneOn` = ISO date of the earliest day (by `d.date`) whose result is done, else None; `done = any day done or (target and value >= target)`.

### Task 3: Today card as a to-do list (app)

**Files:** Modify `src/components/home/TodayCard.tsx`, `src/components/home/TodayCard.test.tsx`.

**Interfaces:** Consumes `ItemRow` (Task 2), `api.putDayProgress(date, {results})`, `DayPlan.progress[id].doneOn` (Task 1/2).
